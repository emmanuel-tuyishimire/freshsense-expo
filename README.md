# FreshSense 🍃

> Intelligent Freshness, Zero Waste. | Sustainable Tech Innovation · Egypt

FreshSense is a biodegradable smart sticker system powered by plant-based chromatic inks. Designed to fight post-harvest food loss across Egypt's supply chain, it transforms how freshness is tracked, turning every grocery purchase into a confident, data-backed decision while saving households an average of EGP 900 annually.

## 🚀 Live Demo
[View the Live Website Here](https://emmanuel-tuyishimire.github.io/freshsense-expo) 

## ✨ Key Features
* **Smart Chromatic Sensors:** Utilizes food-safe, plant-based inks that visually shift from green (Fresh) to yellow (Use Soon) to red (Expired) based on real-time microbial thresholds.
* **Interactive ROI Calculator:** Empowers consumers to input their monthly grocery spend and instantly visualize projected financial savings, CO₂ emissions avoided, and meals saved.
* **UN SDG Alignment:** Directly targets and advances Zero Hunger (SDG 2), Responsible Consumption (SDG 12), and Climate Action (SDG 13) by preventing organic waste from reaching landfills.
* **Localized Ecosystem:** Features a fully Egyptian supply chain, from AUC chemistry research using Delta-grown crops to NFSA-certified manufacturing and hypermarket pilot launches.
